# sfqa-scar

This package is an alias for [`@sfqa/scar`](https://www.npmjs.com/package/@sfqa/scar).
It exists so that `npx sfqa-scar` works without typing the scope. It contains no
code of its own beyond a launcher that runs `@sfqa/scar` with your arguments.

```bash
npx sfqa-scar .                      # scan the current directory
npm install -D @sfqa/scar            # or install the real package
```

Documentation, rules, the proof and the source live in the main repository:
https://github.com/desardavaishali/sfqa-scar

Apache-2.0.
